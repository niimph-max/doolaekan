# ย้ายอีเมลรหัสเข้าระบบออกจาก Gmail ส่วนตัว

## ทำไมต้องย้าย

ตอนนี้ Supabase ส่งรหัสผ่าน SMTP ของ Gmail ส่วนตัวเจ้าของ ซึ่งมีปัญหาสามข้อ
และข้อที่สามคือเหตุผลที่ต้องทำก่อนเปิดให้คนนอกใช้

1. **จำกัดวันละ ~500 ฉบับ** ชนเมื่อไหร่คือทุกคนเข้าระบบไม่ได้พร้อมกัน และ
   Google ไม่ได้บอกล่วงหน้าว่ากำลังจะชน
2. **คนแปลกหน้าเห็นอีเมลส่วนตัวของเจ้าของเป็นผู้ส่ง** ซึ่งเปิดเผยเกินจำเป็น
   และย้อนกลับไม่ได้เมื่อส่งไปแล้ว
3. **app password ที่ใช้อยู่เคยหลุดในภาพหน้าจอ และยังไม่ได้เพิกถอน** —
   ไม่ได้อยู่ใน git และไม่ได้อยู่ในโปรเจกต์นี้ แต่ยังใช้ได้อยู่จนกว่าจะไปถอนเอง

## ใช้เจ้าไหน

**Resend** — เหมาะที่สุดกับสถานการณ์นี้ ฟรี 3,000 ฉบับ/เดือน (100/วัน)
ยืนยันโดเมนด้วย DNS ซึ่ง doolaekan.com อยู่ที่ Cloudflare อยู่แล้ว ตั้งไม่กี่นาที

ถ้าวันไหนต้องการเกิน 100 ฉบับ/วัน **Brevo** ให้ 300/วัน ฟรี ขั้นตอนฝั่ง Supabase
เหมือนกันทุกอย่าง ต่างแค่ค่า host/port/user ที่เอามาใส่

> เลข 100/วัน ฟังดูน้อย แต่รหัสหนึ่งฉบับ = เข้าระบบหนึ่งครั้ง ไม่ใช่ทุกครั้งที่
> เปิดแอป ใบเข้าระบบอยู่ได้เป็นเดือน ครอบครัวเดียวใช้ไม่กี่ฉบับต่อเดือน

## ขั้นตอน

### 1. ยืนยันโดเมนที่ผู้ให้บริการ
สมัคร → Domains → เพิ่ม `doolaekan.com` → เอาเรคคอร์ด DNS ที่เขาให้ (SPF, DKIM
และ DMARC ถ้ามี) ไปใส่ใน Cloudflare

**เรคคอร์ดพวกนี้ต้องตั้ง Proxy เป็น DNS only (เมฆสีเทา)** ถ้าเปิดพร็อกซีไว้
Cloudflare จะบังหน้าไว้แล้วการยืนยันจะไม่ผ่าน โดยขึ้นแค่ว่า "ยังไม่เจอเรคคอร์ด"
ซึ่งเดาสาเหตุไม่ถูกเลย

### 2. สร้าง SMTP credentials
ที่ผู้ให้บริการ → SMTP / API Keys → สร้างใหม่ **คัดลอกเก็บทันที ส่วนใหญ่โชว์ครั้งเดียว**

### 3. ตั้งใน Supabase
Authentication → Emails → SMTP Settings → เปิด Enable Custom SMTP

| ช่อง | ค่า |
|---|---|
| Sender email | `noreply@doolaekan.com` |
| Sender name | `Doolaekan` |
| Host / Port / Username / Password | ตามที่ผู้ให้บริการให้มา |

### 4. วางเทมเพลตภาษาไทย
Authentication → Emails → Templates → **Magic Link** → วางเนื้อหาจาก
`supabase/email/otp-th.html` ทั้งไฟล์

ชื่อเรื่อง (Subject) ใช้ว่า `รหัสเข้าใช้งาน Doolaekan`
— อย่าใส่ตัวรหัสลงในชื่อเรื่อง เพราะมันจะไปโผล่บนหน้าจอล็อกของมือถือ

> ทำไมเป็นเทมเพลต "Magic Link" ทั้งที่แอปใช้รหัส: Supabase ใช้เทมเพลตนี้กับ
> `signInWithOtp` และจะส่งรหัสมาที่ `{{ .Token }}` เมื่อเทมเพลตมีตัวแปรนั้น
> ของเราไม่มีลิงก์ให้กดเลยสักอันทั้งฉบับ **ตั้งใจ** — แอปนี้ให้พิมพ์รหัสเอง
> การมีลิงก์ในอีเมลขอรหัสคือการฝึกให้ผู้ใช้กดลิงก์ในอีเมลที่อ้างว่ามาจากเรา
> ซึ่งเป็นนิสัยที่คนหลอกลวงใช้ทำมาหากิน และผู้สูงอายุโดนหนักที่สุด

### 5. ตั้งอายุรหัสให้ตรงกับที่เขียนในอีเมล
Authentication → Sessions → Email OTP Expiration → **600 วินาที (10 นาที)**

ถ้าเลือกเลขอื่น **ต้องกลับไปแก้ตัวเลขในเทมเพลตให้ตรง** — อีเมลที่บอกเวลาผิด
คือแอปโกหกผู้ใช้ในที่ที่เราไปแก้ให้เขาไม่ได้แล้ว

### 6. ทดสอบก่อนบอกใคร
1. ออกจากระบบในเบราว์เซอร์โหมดส่วนตัว แล้วขอรหัสด้วยอีเมลที่ไม่ใช่ของเจ้าของ
2. ต้องมาจาก `noreply@doolaekan.com` ไม่ใช่ Gmail เดิม
3. เช็คว่าไม่ตกถังสแปม — ถ้าตก มักเป็นเพราะ DNS ยังไม่ครบหรือยังไม่แพร่
4. เข้าระบบด้วยรหัสนั้นให้สำเร็จจริง

### 7. ปิดประตูเก่า — ข้อนี้ห้ามลืม
เมื่อข้อ 6 ผ่านแล้ว ไปที่บัญชี Google ของเจ้าของ → Security → App passwords →
**เพิกถอนตัวที่สร้างไว้ให้ Supabase** เพราะตัวนั้นเคยหลุดในภาพหน้าจอ

ตราบใดที่ยังไม่ถอน ใครที่เห็นภาพนั้นยังส่งอีเมลในนามเจ้าของได้อยู่
และการย้าย SMTP ไปเจ้าใหม่ **ไม่ได้ทำให้รหัสเก่าใช้ไม่ได้** — เป็นคนละเรื่องกัน

## ของที่ยังทำไม่ได้ตอนนี้ และรู้ไว้ก่อน

- **`noreply@` รับอีเมลตอบกลับไม่ได้** ถ้ามีคนตอบกลับมาจะเด้งทิ้ง ในเนื้ออีเมล
  จึงไม่ได้ชวนให้ตอบกลับ และบอกที่อยู่เว็บไว้แทน ถ้าวันหลังอยากรับจริง
  ต้องตั้งกล่องรับของโดเมนแยกต่างหาก
- **DMARC** ตั้งเป็น `p=none` ไปก่อนได้ แล้วค่อยเข้มขึ้นเมื่อแน่ใจว่าไม่มีอะไร
  ส่งในนามโดเมนนี้อีก — ตั้งเข้มตั้งแต่แรกโดยไม่ได้ดูรายงานคือทางที่อีเมล
  หายเงียบโดยไม่มีใครรู้
