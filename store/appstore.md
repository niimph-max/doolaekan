## 3. คำอธิบาย (Description · ≤4000 ตัวอักษร)

```
ดูแลกัน — สมุดสุขภาพของคุณ และของคนที่คุณเป็นห่วง

จดยา นัดหมอ ความดัน อาการ และผลตรวจไว้ที่เดียว เปิดดูได้ทุกเครื่อง
และถ้าคุณดูแลพ่อแม่หรือคนในครอบครัว แชร์ให้เขาเห็นด้วยได้ตามที่ตกลงกัน

■ ยา
เก็บยาทุกตัวพร้อมวิธีกินและ "ช่วยอะไร" เตือนเมื่อเจอยาที่อาจซ้ำกัน
ซึ่งเป็นเรื่องที่เกิดขึ้นจริงเมื่อหมอคนละคนสั่งยาฤทธิ์เดียวกัน
กดบันทึกว่ากินแล้วหรือยัง ทุกคนที่แชร์กันเห็นตรงกันทันที

■ นัดหมอ
วันนัด สถานที่ ใครพาไป และหมายเหตุที่ต้องจำ เช่น งดน้ำงดอาหารกี่ชั่วโมง
เตือนล่วงหน้า 1 วันและเช้าวันนัด ถ่ายเก็บใบนัดไว้กันหาย

■ ความดันและอาการ
จดค่าความดันเป็นชุด ดูย้อนหลังได้ ตั้งข้อเฝ้าระวังประจำตัวไว้ได้ว่า
อาการไหนต้องรีบพบหมอ แล้วแอปจะเตือนตอนจดอาการนั้น

■ เอกสารจากโรงพยาบาล
ถ่ายเก็บผลตรวจ ใบรับรอง ใบเสร็จ ใส่ได้หลายแผ่นต่อหนึ่งใบ
เปิดดูตอนไหนก็ได้ ไม่ต้องรื้อกล่องเอกสารที่บ้าน

■ บันทึกประจำวัน
ออกกำลังกาย อาหาร และเรื่องที่อยากจดไว้ สำหรับคนที่อยากดูแลตัวเองด้วย

■ แชร์เท่าที่อยากแชร์
สมุดของแต่ละคนเป็นของคนนั้น จะเก็บไว้คนเดียว แชร์เฉพาะวันนัด
หรือให้เห็นทั้งหมด เลือกเองได้ และเปลี่ยนใจได้ทุกเมื่อ
ทุกบันทึกบอกว่าใครเป็นคนกด จะได้ไม่ต้องเดาว่าใครทำอะไรไว้

■ ทำมาเพื่อผู้สูงอายุจริงๆ
ตัวหนังสือใหญ่ ปุ่มใหญ่ ภาษาไทยทั้งแอป จำวันเกิดไม่ได้ก็กรอกแค่อายุได้
จำวันฉีดวัคซีนได้แค่ปีก็ลงแค่ปีได้ ไม่บังคับให้กรอกเป๊ะจนต้องเดามั่ว

■ สัญญาสี่ข้อ
1. ไม่มีโฆษณา ไม่ขายข้อมูล ไม่มีอะไรให้ซื้อในแอป
2. แอปจะไม่โกหกคุณ — ยอดที่กรอกไม่ครบจะบอกว่ามาจากกี่รายการ
   วันที่ที่รู้แค่ปีจะแสดงแค่ปี ดึงข้อมูลไม่สำเร็จจะบอกว่าไม่สำเร็จ
   ไม่ทำเป็นว่าไม่มีข้อมูล
3. ของที่คุณพิมพ์หรือถ่ายไว้จะไม่หายเพราะกดพลาด ปิดหน้าต่างแล้วของยังอยู่
   ลบต้องถามก่อนเสมอ
4. ลบบัญชีพร้อมข้อมูลทั้งหมดได้เองในแอป ไม่ต้องส่งอีเมลขอ

ใช้ได้ที่ doolaekan.com ด้วย ข้อมูลชุดเดียวกัน
```

⚠️ ถ้าอยากได้ฉบับภาษาอังกฤษด้วย บอกได้ เดี๋ยวแปลให้ (ไม่ใช่แปลตรงตัว
เพราะสำนวนแบบนี้แปลตรงตัวแล้วแข็ง)

## 6. App Privacy (ป้ายข้อมูลที่โชว์หน้าร้าน)

ตอบตามนี้ได้เลย ตรงกับที่แอปทำจริงและตรงกับหน้านโยบายที่ /privacy

**Data used to track you** → **ไม่มี** (แอปนี้ไม่มีตัวติดตามใดๆ ไม่มี SDK โฆษณา)

**Data linked to you** — ผูกกับบัญชีทั้งหมด เพราะเป็นสมุดของคนคนนั้น

| ประเภท | เก็บอะไร | ใช้ทำอะไร |
|---|---|---|
| Contact Info → Email Address | อีเมลที่ใช้เข้าระบบ | App Functionality |
| Health & Fitness → Health | ยา ความดัน อาการ นัดหมอ วัคซีน ผลตรวจ | App Functionality |
| Health & Fitness → Fitness | บันทึกออกกำลังกาย | App Functionality |
| User Content → Photos or Videos | รูปถุงยา ใบนัด เอกสารที่ผู้ใช้ถ่ายเอง | App Functionality |
| User Content → Other User Content | ข้อความที่ผู้ใช้พิมพ์ (อาการ หมายเหตุ) | App Functionality |
| Identifiers → User ID | รหัสบัญชี | App Functionality |

**Data not collected** — ตำแหน่งที่ตั้ง, รายชื่อผู้ติดต่อ, ประวัติการค้นหา,
ข้อมูลการใช้งาน/analytics, ข้อมูลการเงิน, โฆษณา
(แอปไม่มีตัวเก็บสถิติการใช้งานเลยสักตัว)

⚠️ แอปเปิลจะถามต่อว่า "ใช้เพื่อ Analytics หรือ Product Personalization ไหม"
ตอบ **ไม่** ทุกข้อ ใช้เฉพาะ App Functionality อย่างเดียว

## 7. Age Rating

ตอบ **None / ไม่มี** ทุกข้อในแบบสอบถาม → ได้เรต **4+**

⚠️ ข้อที่ต้องคิดหน่อยคือ **Medical/Treatment Information**
แอปนี้ *ไม่ได้* ให้คำแนะนำทางการแพทย์ ไม่วินิจฉัย ไม่บอกว่าควรกินยาอะไร
มันแค่เก็บสิ่งที่ผู้ใช้กรอกเอง — ตอบ None ได้ตามตรง
ถ้าวันหลังเพิ่มอะไรที่ตีความว่าเป็นคำแนะนำ ต้องกลับมาแก้ข้อนี้

## 8. หมายเหตุถึงผู้ตรวจ (App Review Information → Notes)

**สำคัญที่สุดของทั้งไฟล์** — ระบบเข้าระบบเป็นรหัสที่ส่งไปทางอีเมล
ผู้ตรวจรับอีเมลของเราไม่ได้ ถ้าไม่บอกทางเข้า เขาจะเปิดแอปแล้วไปต่อไม่ได้
แล้วตีกลับด้วยเหตุผลว่าเข้าใช้งานไม่ได้ ซึ่งเสียเวลาไปหนึ่งรอบเต็มๆ

```
This app is in Thai and is a shared health record for families.

HOW TO REVIEW WITHOUT AN ACCOUNT
On the first screen, tap the second button "ดูโหมดตัวอย่างก่อน"
(= "Try the demo first"). It opens the full app with sample data.
No account, no email, no network needed. Every feature is usable there.

SIGN-IN (if you prefer a real account)
Sign-in is a 6-digit code sent by email. If you need a live account,
please contact us and we will provide one.

ACCOUNT DELETION
In the app: สมุด (Book tab) → ตั้งค่าสมุด (Book settings) → scroll to
the bottom → "ลบบัญชีและข้อมูลทั้งหมด" (Delete account and all data).
It asks the user to type a confirmation word, then deletes everything.

PRIVACY POLICY
https://doolaekan.com/privacy/ — public, no login required.

NOTIFICATIONS
Used for appointment reminders, high blood pressure alerts to family
members who were given access, and one optional morning summary.
The user turns them on themselves in Book settings. Nothing is sent
unless they do.

The app does not provide medical advice. It only stores what the user
enters, and shares it with the family members that the user chooses.
```

⚠️ ถ้าจะให้บัญชีทดสอบจริงแทนโหมดตัวอย่าง ต้องสร้างบัญชีที่รับอีเมลได้
และใส่ email/password ในช่อง Demo Account — แต่ระบบเราไม่มีรหัสผ่าน
มีแต่รหัสทางอีเมล **โหมดตัวอย่างจึงเป็นทางที่ถูกต้องกว่า**
