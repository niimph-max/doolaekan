# Handoff: Doolaekan — แอปสมุดสุขภาพครอบครัว

## Overview
แอปมือถือสำหรับบันทึกและแชร์การดูแลสุขภาพในครอบครัว (ผู้ใช้หลักคือลูกๆ ที่ดูแลพ่อแม่สูงอายุ):
นัดหมอ + แจ้งเตือน, รายการยาพร้อมคำอธิบาย "ยาตัวนี้ช่วยอะไร" + เช็คยาซ้ำข้ามหมอ, บันทึกกินยา (รวมเคส "ไม่ยอมกิน"),
วัดความดัน/น้ำตาล, จดอาการ + ข้อเฝ้าระวังประจำตัว, สแกนเอกสาร/ถุงยา, บัตรสรุปฉุกเฉินสำหรับยื่นให้หมอ,
และระบบกลุ่มครอบครัวแบบยินยอมแชร์รายสมุด

## สถานะตอนนี้ — มีแอปจริงแล้ว
`src/` คือแอปจริง (Next.js App Router + TypeScript, PWA ติดตั้งลงหน้าจอได้) ที่สร้างตามต้นแบบในไฟล์นี้

แอปทำงานได้ **2 โหมด** ตัดสินจากตัวแปรใน `.env.local`:
- **เครื่องเดียว** (ไม่ใส่ค่า) — เก็บทุกอย่างใน `localStorage` ใช้คนเดียวได้เลย ไม่ต้องล็อกอิน
- **คลาวด์** (ใส่ค่า Supabase) — ล็อกอินด้วยรหัส 6 หลักทางอีเมล ข้อมูลอยู่บน Supabase
  ซิงก์สดข้ามเครื่องด้วย Realtime รูปเก็บใน Storage และ RLS บังคับสิทธิ์การเห็นจริงที่ฐานข้อมูล

```bash
npm install
cp .env.example .env.local   # ใส่ค่าถ้าจะใช้โหมดคลาวด์
npm run dev                  # http://localhost:3000
npm run build                # ตรวจ type + export ไฟล์นิ่งลง out/
```

แอปคุยกับ Supabase จากเบราว์เซอร์ตรงๆ ไม่มีฝั่งเซิร์ฟเวอร์ของตัวเอง จึง `output: 'export'`
เป็นไฟล์นิ่ง เอาไปวางบน static host ไหนก็ได้

### ขึ้น GitHub Pages (ตั้งครั้งเดียว)
`.github/workflows/deploy-pages.yml` build แล้ว deploy ให้อัตโนมัติทุกครั้งที่ push

1. **Settings → Pages → Source** เลือก **GitHub Actions**
2. **Settings → Secrets and variables → Actions → New repository secret** เพิ่ม 2 ตัว:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. **Actions → Deploy to GitHub Pages → Run workflow** (หรือรอ push ครั้งถัดไป)
4. ได้ URL `https://<user>.github.io/<repo>/` แล้วเอาไปใส่ที่ Supabase →
   Authentication → URL Configuration (Site URL + Redirect URLs)

> anon key ถูกฝังในไฟล์ที่ส่งให้เบราว์เซอร์อยู่แล้วโดยธรรมชาติ (เป็นคีย์สาธารณะ)
> ความปลอดภัยจริงอยู่ที่ RLS ไม่ใช่การซ่อนคีย์ — ดู `supabase/tests/`

`NEXT_PUBLIC_BASE_PATH` ทำให้แอปอยู่ใต้ `/<repo>/` ได้ ตอน dev ในเครื่องไม่ต้องตั้ง
manifest ใช้ path แบบ `./` และ service worker อ่าน scope ของตัวเอง จึงทำงานถูกทั้งสองแบบ

### ตั้งค่า Supabase (ทำครั้งเดียว)
1. **รัน migration** — SQL Editor รัน `supabase/migrations/0001_init.sql` แล้วตามด้วย `0002_join_group.sql`
   (สร้างตาราง + RLS + bucket `scans`/`med-photos` + เปิด Realtime ให้ครบในตัว)
2. **คีย์** — Project Settings → API Keys → ก๊อป `anon` key ใส่ `.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon key>
   ```
3. **Auth** — Authentication → Sign In / Providers → Email ต้อง Enabled (ค่าเริ่มต้นเปิดอยู่)
4. **อีเมลรหัส 6 หลัก** — Authentication → Emails → เทมเพลต **Magic Link**
   ใส่ `{{ .Token }}` ลงในเนื้อเมล (แทน/เพิ่มจาก `{{ .ConfirmationURL }}`)
   เพราะหน้าล็อกอินในแอปรับเป็นรหัส 6 หลัก
5. **URL Configuration → Site URL** — ตั้งเป็น `http://localhost:3000` ตอนพัฒนา และโดเมนจริงตอน deploy

เปิดครั้งแรกในโหมดเครื่องเดียวจะเข้า onboarding 5 ขั้น หรือกด **"ดูโหมดตัวอย่างก่อน"** เพื่อดูหน้าตาแอปตอนมีข้อมูลครอบครัวสมมติ
ถ้าเคยใช้โหมดเครื่องเดียวมาก่อนแล้วมาต่อคลาวด์ทีหลัง จะมีปุ่ม **"ยกข้อมูลในเครื่องขึ้นคลาวด์"** ให้ย้ายของเดิมขึ้นไป (id เป็น uuid อยู่แล้วจึงยกขึ้นตรงๆ ได้)

ทำได้แล้ว:
- onboarding 5 ขั้น (ชื่อ/ที่อยู่ → โรคประจำตัว+แพ้ยา → หมอ+HN+เวลาออกตรวจ → ครอบครัว → ระดับแชร์)
- แท็บ **วันนี้**: นัดถัดไป, ยาวันนี้จัดเป็นมื้อ (กินแล้ว / ไม่ยอมกิน + เหตุผล), จดอาการ, วัดความดัน, บัตรฉุกเฉิน
- แท็บ **ยา**: รายการยา + "ช่วยอะไร", เช็คยาซ้ำอัตโนมัติ + ติดธง, สแกนถุงยา (ถ่ายรูป+ยืนยันข้อความ), พิมพ์เพิ่มเอง
- แท็บ **นัดหมอ**: 3 ขั้น (ตรวจเลือด ≤7 วันก่อนนัด → พบหมอ → กลับบ้านสแกนถุงยา), มอบหมายคนพาไป, เพิ่มนัดใหม่
- แท็บ **สมุด**: สลับกลุ่ม/สร้าง/เข้ากลุ่มด้วยรหัส, ตั้งสิทธิ์รายสมุด, ข้อเฝ้าระวัง, กราฟความดัน, ไทม์ไลน์ + สแกนเอกสาร
- "คนกดตอนนี้" — ทุกบันทึกติดชื่อคนกด + เวลา
- ข้อเฝ้าระวัง: จดอาการที่ตรงกติกา → เตือนด่วน + ปุ่มโทร รพ. + ติดจุดส้มในไทม์ไลน์
- PWA: manifest + service worker + ไอคอน (ติดตั้งลงหน้าจอเครื่องเตี่ย/แม่ได้)
- **โหมดคลาวด์**: ล็อกอินอีเมล OTP, เขียนแบบ optimistic (จอตอบทันที เขียนขึ้นคลาวด์ตามหลัง พลาดแล้วดึงของจริงกลับมา),
  Realtime บน `med_logs`/`records`/`appointments`/`medications`, อัปโหลดรูปเข้า Storage + signed URL

ยังไม่ได้ทำ (ขั้นต่อไป):
1. **แจ้งเตือน** ตาม `notifications.md` — Web Push (VAPID) + Edge Function `notify` + pg_cron แล้วค่อย LINE
   (`sw.js` ยังไม่มี push handler, ตาราง `push_subscriptions`/`notified_log` เตรียมไว้แล้ว)
2. **OCR ถุงยา** — ตอนนี้ถ่ายรูปได้ แต่ต้องพิมพ์ข้อความเอง
3. **QR จริง** สำหรับเข้ากลุ่ม (ตอนนี้ใช้รหัส `DLK-xxxx` พิมพ์เอา — ฝั่งหลังบ้านพร้อมแล้วผ่าน `join_group_by_code`)
4. **แก้/ลบ** ยา นัด และบันทึกในไทม์ไลน์ (ตอนนี้เพิ่มได้อย่างเดียว ยกเว้นหมอที่ลบได้)

## About the Design Files
ไฟล์ในชุดนี้เป็น **design reference ที่สร้างด้วย HTML** (Design Component prototype) — ใช้ดู look & behavior ที่ตั้งใจไว้
**ไม่ใช่โค้ด production** งานของผู้พัฒนาคือ recreate ดีไซน์นี้ในสภาพแวดล้อมจริงของ repo (แนะนำ React/Next.js หรือ Expo React Native + Supabase)
ตาม pattern ของ codebase เอง

- `Doolaekan.dc.html` — ต้นแบบหลัก (เปิดในเบราว์เซอร์ได้ ลอจิกอยู่ใน `<script>` ท้ายไฟล์)
- `organic.css` — design tokens + component classes ของระบบดีไซน์ "Organic"

## Fidelity
**High-fidelity** — สี ตัวอักษร ระยะ และ interaction ในต้นแบบคือของจริงที่ต้องการ ยกเว้น:
รูปภาพ/รูปโปรไฟล์เป็น placeholder, การสแกน OCR ถุงยาเป็น mock (ต้องต่อ OCR/AI จริง), ข้อมูลโหมดตัวอย่างเป็น dummy

## แนวคิดหลักของระบบ (สำคัญที่สุด)
1. **ของใครของมันก่อน**: ทุกคนมีบัญชี + "สมุด" ส่วนตัว (โรคประจำตัว หมอ HN ยา นัด ประวัติ) ข้อมูลเป็นส่วนตัว 100% โดยค่าเริ่มต้น
2. **กลุ่ม = การยินยอมแชร์**: สร้าง/เข้ากลุ่มด้วย QR หรือลิงก์ การแชร์ตั้งเป็น **รายสมุด**: ทั้งหมด / เฉพาะวันนัด / ยังไม่แชร์
3. **1 คนอยู่ได้หลายกลุ่ม** แยกกันสนิท (บ้านเตี่ย–แม่ กับครอบครัวของน้อง มองไม่เห็นกัน)
4. **สมุดที่แชร์ "ทั้งหมด" ทุกคนในกลุ่มช่วยบันทึกได้** และทุกการบันทึกติดชื่อคนทำ + เวลา (audit trail)
5. **เครื่องผู้สูงอายุ = เครื่องกลางที่บ้าน**: ล็อกอินค้างไว้ มีตัวสลับ "คนกดตอนนี้" ก่อนบันทึก (คนดูแล/ลูกที่แวะมา)

## Screens / Views

### 1. Onboarding (เปิดแอปครั้งแรก)
5 ขั้น เต็มจอ พื้น `--color-bg #f5ead8`:
1. **Welcome** — โลโก้หัวใจในวงกลม `#ffe1d0`, h1 "Doolaekan" (Mitr 36px), ช่อง: ชื่อเรียกในสมุด, ชื่อ-นามสกุลจริง, ที่อยู่ → ปุ่ม primary "เริ่มใช้สมุดของฉัน"
2. **ขั้น 1/3 โรคประจำตัว & แพ้ยา** — chips เลือกหลายอัน (ความดันสูง เบาหวาน โรคหัวใจ ไขมันสูง ต้อกระจก กระดูกพรุน ภูมิแพ้) + ช่องโรคอื่น + ช่องแพ้ยา; ข้ามได้
3. **ขั้น 2/3 หมอที่รักษา** — ฟอร์ม: หมอ/แผนก, รพ./คลินิก, **เลข HN**, **เวลาออกตรวจ**; ปุ่ม "เพิ่มหมอคนนี้" สะสมเป็นรายการ; หมอคนเดียวออกตรวจหลายที่ = เพิ่มซ้ำทีละแห่ง
4. **ขั้น 3/3 ครอบครัว** — 3 ทางเลือก: ใช้คนเดียวก่อน / สร้างกลุ่ม / สแกน QR เข้ากลุ่ม
5. **เลือกระดับแชร์ก่อนเข้ากลุ่ม** — ทั้งหมด / เฉพาะวันนัด / ยังไม่แชร์ (มี QR placeholder)

### 2. หน้าหลัก "วันนี้" (tab 1)
- Kicker "DOOLAEKAN" (12.5px, #b2622d, letter-spacing .12em) + h2 "วันนี้" + วันที่จริง (th-TH) + "คนกดตอนนี้: <ชื่อ> ▾" (แตะเปิด bottom sheet เลือกคน)
- การ์ด **นัดถัดไป** (นับถอยหลัง + บรรทัดเตือน) หรือ empty-state เส้นประ "ยังไม่มีนัดหมอ" กดแล้วเปิดฟอร์มเพิ่มนัด
- **ยาวันนี้**: การ์ดต่อยา — ยังไม่กิน = ขอบส้ม `1.5px solid #d67f48` + ปุ่มใหญ่ "กินแล้ว" (primary) / "ไม่ยอมกิน" (secondary ตัวอักษร #8c491a); กด "ไม่ยอมกิน" → ถามเหตุผลเป็น chips (บอกว่าขม / อิ่มเกิน / อารมณ์ไม่ดี) → บันทึก + แจ้งครอบครัว; กินแล้ว = pill เขียว `#f0fae1` พร้อมเวลา + ชื่อคนบันทึก
- แถว "จดอาการวันนี้" → เปิด symptom sheet
- การ์ด **วัดความดัน**: ช่องเลขใหญ่ 3 ช่อง (ตัวบน/ตัวล่าง/ชีพจร, Mitr 23px, กลาง) + ปุ่ม "บันทึก — ทุกคนเห็นทันที" + ghost "ดูย้อนหลัง" (ไป tab สมุด + filter ความดัน)
- การ์ดเข้ม **บัตรสรุปฉุกเฉิน** (พื้น #402310 ตัวอักษร #ffe1d0 icon #f6a06b)

### 3. ยา (tab 2)
- หัว "ยาของ<ชื่อ>" + จำนวน; การ์ดยา: ชื่อ (Mitr 19px) + tag แผนก + บรรทัด **"ช่วยอะไร:"** (คำอธิบายภาษาบ้านๆ) + วิธีกิน/หมอที่สั่ง
- **การ์ดเตือนยาซ้ำ** (พื้น #fff2eb ขอบ #d67f48): ระบุคู่ยาซ้ำ + "ติดธงไว้ถามหมอนัดหน้า"; ยาที่ถูกธงมีบรรทัด "⚑ ติดธงยาซ้ำ"
- ปุ่ม "สแกนถุงยาใหม่" → sheet: viewfinder → ผล OCR (ชื่อยา วิธีกิน ได้จาก) + "แอปเติมให้: ช่วยอะไร" + เช็คยาซ้ำอัตโนมัติ → บันทึก

### 4. นัดหมอ (tab 3)
- รายการนัด (การ์ด: icon ปฏิทินวงกลมเขียว, ชื่อ, วันเวลา, tag "อีก X วัน")
- นัดหมอหัวใจแสดง **3 ขั้น**: ① ตรวจเลือดล่วงหน้า (≤7 วันก่อนนัด — แอปแนบให้อัตโนมัติเมื่อชื่อนัดมี "หัวใจ") ② พบหมอ (เตือน 1 วันก่อน + เช้าวันนัด) ③ กลับบ้านสแกนถุงยาใหม่ + เตรียมตัว/มอบหมายใครพาไป (chips ชื่อพี่น้อง)
- ปุ่ม "เพิ่มนัดใหม่" → sheet: หมอ/เรื่อง, วันที่ (date picker), เวลา, สถานที่ + โน้ตกติกาตรวจเลือดอัตโนมัติ

### 5. สมุด (tab 4)
- หัว "สมุดสุขภาพ" + ปุ่มกลุ่ม "<ชื่อกลุ่ม> ▾" (เปิด sheet สลับกลุ่ม/สร้างกลุ่ม) + ปุ่ม "โปรไฟล์ & หมอ"

- การ์ด **ข้อเฝ้าระวังของ<ชื่อ>** (เช่น "เคืองตา/เจ็บตา → พบหมอทันที (หมอตา)")
